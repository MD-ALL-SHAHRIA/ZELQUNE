# SFX credits

Every sound in this folder and assets/music.mp3 is original, synthesised by scripts/compose_audio.py
for Zelqune. There are no third-party samples, so nothing needs attribution and commercial use is fine.

Pixabay and Freesound were considered, but both require an account/API key to download, and the
project rules need the owner's approval for sign-ups. To swap in downloaded sounds, keep the same
file names (key-1..8, click, toggle, pop, tick, chime, shimmer, whoosh-1..3, riser, impact) and list
each file here with its source URL and licence (Pixabay Content License, CC0, or CC-BY with credit).
