# Zelqune প্রি-অর্ডার ওয়েবসাইট: স্পেসিফিকেশন v1

**তারিখ:** ১৮ অক্টোবর ২০২৬ · **বানাবেন:** মালিক (সফটওয়্যার ইঞ্জিনিয়ার) · **বাংলা লেখা আর রিভিউ:** Claude

## লক্ষ্য
এটা পুরো অনলাইন দোকান নয়। এটা এক পাতার পরীক্ষামূলক সাইট। এর কাজ একটাই প্রশ্নের উত্তর বের করা: অচেনা মানুষ কি অগ্রিম টাকা দিয়ে আলো-আর্চ প্যানেল প্রি-অর্ডার করবে?

**GO-র শর্ত:** বন্ধু-পরিচিত নয় এমন ১০ জন বা তার বেশি মানুষ অগ্রিম টাকা দিয়ে প্রি-অর্ডার করলে GO।

## প্রযুক্তি (প্রস্তাব, আপনার পছন্দমতো বদলাতে পারেন)
- **সাইট:** স্ট্যাটিক সাইট। প্লেইন HTML + Tailwind দিয়ে বানাতে পারেন, অথবা Astro/Next-এর static export।
- **হোস্টিং:** Cloudflare Pages, Netlify বা GitHub Pages-এ রাখলে খরচ শূন্য। শুরুতে তাদের দেওয়া ফ্রি সাবডোমেইনই যথেষ্ট।
- **ডোমেইন:** zelqune.com কেনা হবে শুধু GO-র পরে, আপনার অনুমতি নিয়ে।
- **ডেটা:** ফর্মের তথ্য যাবে Google Sheet-এ, Apps Script-এর web app endpoint দিয়ে। আলাদা কোনো ডেটাবেস লাগবে না।
- **পেমেন্ট:** এখন কোনো পেমেন্ট গেটওয়ে নয়। ক্রেতা bKash বা Nagad-এ অগ্রিম পাঠাবেন, ফর্মে Transaction ID দেবেন, আর আপনি হাতে মিলিয়ে দেখবেন।
- **গতি:** সাইট আগে মোবাইলের জন্য বানাবেন, কারণ প্রায় সব ভিজিটর আসবে Facebook-এর মোবাইল অ্যাপ থেকে। ছবি WebP ফরম্যাটে রাখবেন, প্রতিটা ২০০ KB-র কম। 4G-তে পুরো পাতা ২ সেকেন্ডের মধ্যে লোড হওয়ার লক্ষ্য।

## পাতার অংশ (উপর থেকে নিচে)
১. **হিরো:** প্রোটোটাইপের আসল ছবি (আলো জ্বালানো অবস্থায়), এক লাইনের শিরোনাম, দাম, আর "প্রি-অর্ডার করুন" বোতাম।
২. **কী পাচ্ছেন:** মাপ (৩২×৬৪ সেমি), উপাদান (ওয়ালনাট ভিনিয়ার + ক্রিম ফ্রেম), ৫V USB উষ্ণ আলো, কাচের টিউব, দেয়ালে লাগানোর কিট।
৩. **ছবি:** ৩–৪টা আসল ছবি। একটা দিনের বেলার, একটা রাতে আলো জ্বালানো, একটা দেয়ালে লাগানো অবস্থায় যাতে মাপটা বোঝা যায়, আর একটা কাছ থেকে তোলা ডিটেইলের।
৪. **কীভাবে প্রি-অর্ডার কাজ করে:** অর্ডার অনুযায়ী বানানো হবে, অগ্রিম কত টাকা, কত দিনে ডেলিভারি (সংখ্যাটা প্রোটোটাইপের পর ঠিক হবে), বাকি টাকা ক্যাশ অন ডেলিভারিতে।
৫. **ফর্ম** (ঘরগুলো নিচে দেওয়া)।
৬. **প্রশ্নোত্তর:** আলো কি নিরাপদ (৫V, কাঠের ভেতরে ২২০V নেই), কীভাবে লাগাতে হয়, যত্ন কীভাবে নিতে হয়, অগ্রিম কখন ফেরত পাবেন।
৭. **শর্ত:** নির্দিষ্ট সময়ের মধ্যে পণ্য দিতে না পারলে অগ্রিম পুরো ফেরত দেওয়া হবে। ফোন নম্বর শুধু অর্ডারের কাজে ব্যবহার হবে।
৮. **ফুটার:** Facebook আর Instagram লিংক, WhatsApp বা ফোন নম্বর।

## ফর্মের ঘর (Google Sheet-এর কলাম)
`timestamp, name, phone, district, area/thana, full_address, finish (walnut/natural), quantity, price_shown, bkash_trx_id, utm_source, utm_campaign, note`

শুধু আপনি পূরণ করবেন এমন কলাম: `paid_verified (Y/N), is_friend (Y/N), status`

GO গোনার সূত্র: `paid_verified=Y` আর `is_friend=N` আছে এমন সারি কয়টা।

## দামের পরীক্ষা
- দুটো দাম পরীক্ষা হবে: ৩,৪৯০ আর ৪,২৯০ টাকা।
- আলাদা বিজ্ঞাপন বা লিংক দিয়ে ভাগ করবেন: `?p=a` হলে ৩,৪৯০ দেখাবে, `?p=b` হলে ৪,২৯০।
- একজন ভিজিটর যে দাম দেখেছে, পাতা রিফ্রেশ করলেও যেন সেই দামই দেখে।
- কোন দাম দেখানো হয়েছিল তা `price_shown` কলামে সেভ হবে।

## ট্র্যাকিং
- Meta Pixel বসাবেন। ইভেন্ট: পাতা খুললে `ViewContent`, প্রি-অর্ডার বোতামে চাপলে `InitiateCheckout`, ফর্ম জমা হলে `Lead`।
- Facebook পোস্ট আর বিজ্ঞাপনের প্রতিটা লিংকে UTM থাকবে।
- Pixel ID পাওয়া যাবে Facebook পেজ আর Business Manager খোলার পর।

## যা করা যাবে না
- ভুয়া রিভিউ, "১২ জন অর্ডার করেছে" ধরনের বানানো কাউন্টার, বা মিথ্যা কাউন্টডাউন টাইমার।
- "স্টকে আছে" লেখা। পরিষ্কার লিখতে হবে যে এটা প্রি-অর্ডার।
- অন্যের পণ্যের ছবি। শুধু আমাদের প্রোটোটাইপের আসল ছবি ব্যবহার হবে।

## কাজের ক্রম
১. **এখন:** কাঠামো, ফর্ম থেকে Sheet-এ ডেটা যাওয়া, আর Pixel-এর জায়গা তৈরি রাখবেন। ছবির জায়গায় আপাতত placeholder। এতে ১–২ দিনের বেশি সময় দেবেন না। ওয়ার্কশপে যাওয়া আগে।
২. **Claude:** বাংলায় সব লেখা দেবে (শিরোনাম, বর্ণনা, প্রশ্নোত্তর, শর্ত)।
৩. **প্রোটোটাইপের পর:** আসল ছবি বসবে, ডেলিভারির দিন আর দাম চূড়ান্ত হবে।
৪. **লঞ্চের আগে:** Claude পুরো সাইট রিভিউ করবে। আপনি নিজে ২টা পরীক্ষামূলক অর্ডার দিয়ে Sheet-এ ঠিকমতো আসছে কিনা দেখবেন, তারপর সেগুলো মুছে দেবেন।
৫. **লঞ্চ:** আপনার অনুমতি নিয়ে লঞ্চ হবে। বিজ্ঞাপনের খরচ ২০,০০০ টাকার ঝুঁকির বাজেট থেকে।
